# SC2 Smart Export Foundation

This module decides which imported map files should be preserved unchanged and which files must be patched or regenerated.

## Included pieces

- `SC2DirtyFlags` - dirty/stale flags for map data domains.
- `SC2ExportFileState` - per-file state, original bytes, generated bytes, mode, warnings, errors.
- `SC2ExportDependencyGraph` - dependency expansion, for example terrain geometry makes hfield/costs/collision2 stale.
- `SC2SmartExportPlanner` - evaluates file states against dirty flags.
- `SC2SmartExportWriter` - writes a folder export using passthrough bytes for unchanged files.
- `SC2SmartExportReport` - creates `sc2_export_report.md`.

## File modes

- `OriginalPassthrough` - write original bytes unchanged.
- `Patched` - write patched bytes.
- `Regenerated` - write regenerated bytes.
- `Missing` - source file was not present.
- `SkippedBecauseUnchanged` - intentionally skipped by caller.
- `BlockedByValidationError` - export cannot write this file.

This is the foundation layer. Higher-level import/export code should provide original file bytes from `.scd`/`scenario.lua` discovery and regenerated bytes from terrain/hfield/costs/collision/object serializers.
